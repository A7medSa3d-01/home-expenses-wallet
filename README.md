# Home Wallet

A complete client-side home expense tracker built with HTML, CSS and Vanilla JavaScript.

## Run
Open `index.html` in a modern browser. No server or build step is required.

## Features
- Monthly calendar with daily expense totals
- Add, edit and delete daily expenses
- Monthly house / lessons / total summary
- Two independent student lesson pages
- Monthly paid/unpaid tracking per lesson
- Lesson management page
- Student names, currency and dark mode settings
- LocalStorage persistence
- JSON backup export
- Responsive desktop/mobile UI
- No CSS linear gradients and restrained shadows

All application data is stored locally in the browser.
